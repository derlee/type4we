# 使用

[English](../en/usage.md)

## 第一次打开

Type4We 出现在通知区域。左键或右键托盘图标，选**设置**。窗口的关闭按钮只是隐藏；**退出**才会结束进程。

1. **服务**保持火山引擎。在[火山引擎控制台](https://console.volcengine.com/)的豆包语音里创建应用，并开通流式语音识别。默认资源 ID 是 `volc.seedasr.sauc.duration`（2.0，按音频时长计费）。菜单里还有 2.0 并发版，以及 1.0 的 `volc.bigasr.sauc.*`。
2. 旧版控制台填写 App ID 和 Access Token，点**保存凭据**。Token 不会回写到输入框。新版控制台把鉴权方式改成 API Key 再保存。这些值不会写入 `config.json`。
3. 若改用 Soniox，切换服务，到 [console.soniox.com](https://console.soniox.com) 保存密钥，模型保持 `stt-rt-v6`（`stt-rt-v5` 于 2026-12-15 下线）。语言提示默认 `zh, en`。断句灵敏度默认 `-0.3`。
4. 选按住说话或切换，然后**保存**。

## 听写

把焦点放在普通文本框。按住**右 Alt** 说话，说完松开。

- Soniox 标成最终的词会马上打出来，所以说话过程中就能看到文字。
- 打开浮层时，它显示完整预览，包括还可能变化的词。那些临时词只在结束时写一次。
- 托盘状态会经过启动、聆听、结束。

切换模式：按一次热键开始，再按一次停止。松开无效。

麦克风隐私：如果 Windows 禁止桌面应用使用麦克风，采集会失败，托盘会显示错误。到「设置 → 隐私 → 麦克风」里允许 Type4We 或桌面应用。

## 热键写法

用 `+` 分隔。修饰键：`Ctrl`、`Alt`、`Shift`、`Win`，也可以写左右（`RAlt`、`LCtrl`、`RWin`）。最后一项可以是按键名（`Space`、`F8`、字母、数字）。预设有 `RAlt`、`Ctrl+Win`、`RCtrl`。

`Ctrl+Win` 只在两个键都按下时才被吞掉，所以单独的 Win 键仍然能打开开始菜单。先按住 Ctrl 和 Win 再按左方向键，会和虚拟桌面快捷键冲突，因为和弦在左方向键之前就已经成立。除非 AltGr 碍事，否则更适合用右 Alt。见 [ADR 0004](adr/0004-default-hotkey.md)。

## 注入

| 方式 | 行为 |
| --- | --- |
| 自动 | `SendInput` Unicode。只有当写入的事件数少于请求数时，才用剪贴板和 Ctrl+V。 |
| 仅 Unicode | 只用 Unicode。写入不足会显示错误，不动剪贴板。 |
| 剪贴板 | 总是粘贴，短暂停顿后恢复原来的 Unicode 文本。 |

以管理员身份启动的窗口会丢掉这些输入。这是 UIPI，应用看不出按键失败。把目标程序当成普通用户运行，或者等带 `uiAccess` 的签名版本。见 [ADR 0003](adr/0003-text-injection.md)。

目前只有快速模式。托盘上的模式不是开关。文件里如果存了别的模式名，会留下来供以后导入，现在不会执行。
